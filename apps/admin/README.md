# GGVault Admin

Phase 6B moderator application: authorized login, filtered dispute queue, reported results, private evidence, timeline and confirmed winner/void decisions. Uses the shared server-only session architecture with an independent admin cookie and Redis namespace. See [setup and security](../../docs/match-experience.md#moderator-application).

## Commands

```bash
npm run dev
npm run build
npm run start
npm run lint
npm test
```
